Dieses Theme enthält die [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) Integration und ist in Ihrer `astro.config.mjs` Konfigurationsdatei konfiguriert. Wenn Sie die Verwendung von MDX nicht wünschen, können Sie die Unterstützung durch Entfernen der Integration aus Ihrer Konfigurationsdatei deaktivieren.

## Warum MDX?

MDX ist eine spezielle Variante von Markdown, die eingebettetes JavaScript & JSX-Syntax unterstützt. Dies ermöglicht es, [JavaScript und UI-Komponenten in Ihren Markdown-Inhalt einzubetten](https://docs.astro.build/en/guides/integrations-guide/mdx/#mdx-in-astro) für interaktive Diagramme oder Benachrichtigungen.

Wenn Sie bereits Inhalte in MDX erstellt haben, wird diese Integration Ihnen hoffentlich den Umzug zu Astro erleichtern.
